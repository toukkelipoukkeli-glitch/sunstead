This folder is **generated by Switchboard's Code Rewriter**. It is the PulseBoard
app with Supabase swapped for Aiven:

## Run the whole thing

```sh
# 1. backend
cd api && npm install && cp .env.example .env   # paste Aiven DATABASE_URL
npm run dev                                      # :8089

# 2. front-end (another terminal)
cd .. && npm install && npm run dev              # :5174, talks to :8089
```

Log in with a migrated user (e.g. `ada@pulseboard.dev` / `hunter2`) and the app
runs entirely on Aiven. Storage (avatar upload) is the one intentional gap — see
the migration report.
