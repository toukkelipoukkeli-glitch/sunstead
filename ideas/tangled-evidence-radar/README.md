# Tangled Evidence Radar

Sunstead Hack project for the **Tangled** challenge (AT Protocol).

Tangled Evidence Radar gives maintainers one prioritized review queue and shows
the portable protocol evidence behind every recommendation.

## Run

```sh
npm install
npm run dev      # vite dev server
npm run build    # type-check + production build
```

React + Vite + TypeScript. The UI opens directly on the maintainer queue for
`solar-knot/payments` with seeded Tangled records.
